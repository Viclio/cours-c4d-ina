# Cinema 4D – Supports de cours (INA)

Site des supports de cours, publié avec GitHub Pages : https://viclio.github.io/cours-c4d-ina/

Chaque semaine a sa propre adresse et son propre sommaire :

- Semaine 1 : https://viclio.github.io/cours-c4d-ina/semaine-1/
- Semaine 2 : https://viclio.github.io/cours-c4d-ina/semaine-2/

Pour modifier le cours : voir [GUIDE-EDITION.md](GUIDE-EDITION.md).

## Contenu du dépôt

| Fichier ou dossier | Rôle |
|---|---|
| `index.md` | Accueil général (liste des semaines) |
| `semaine-1/`, `semaine-2/` | Une semaine par dossier : `index.md` (accueil de la semaine), `jour-1.md` … `jour-5.md`, `credits.md`, `images/` |
| `_data/semaines.yml` | Titre, sous-titre et résumé de chaque semaine |
| `videos/` | Vidéos hébergées dans le dépôt (facultatif) |
| `_config.yml` | Titre et réglages du site |
| `_layouts/`, `_includes/`, `assets/` | Mise en page, styles et scripts (à ne modifier que pour changer l'apparence) |
