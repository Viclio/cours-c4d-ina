# Cinema 4D – Support de cours (semaine 1, INA)

Site du support de cours, publié avec GitHub Pages.

- **Lire le cours** : l'adresse du site s'affiche dans *Settings › Pages* une fois la publication activée.
- **Modifier le cours** : voir [GUIDE-EDITION.md](GUIDE-EDITION.md).

## Contenu du dépôt

| Fichier ou dossier | Rôle |
|---|---|
| `index.md` | Page d'accueil |
| `jour-1.md` … `jour-5.md` | Une page par jour de cours |
| `credits.md` | Crédits des illustrations |
| `images/` | Illustrations |
| `videos/` | Vidéos hébergées dans le dépôt (facultatif) |
| `_config.yml` | Titre et réglages du site |
| `_layouts/`, `_includes/`, `assets/` | Mise en page, styles et scripts (à ne modifier que pour changer l'apparence) |
